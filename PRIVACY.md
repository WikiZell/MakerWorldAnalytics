# Privacy

MakerWorldAnalytics collects public MakerWorld information directly from the user's ESP32. MakerWorld account credentials and analytics are not sent to WikiZell or to a WikiZell-operated server.

The device stores the selected Wi-Fi network, local Wi-Fi password, profile identifier, and locally calculated history only in its own non-volatile storage. The default diagnostic-reporting setting is off. GitHub is used for source code, release assets, optional update manifests, and the web installer; normal statistics collection does not depend on GitHub.

The project is independent and unofficial; it is not affiliated with MakerWorld or Bambu Lab.
