# First setup

On a new device, MakerWorldAnalytics creates a WPA2-protected access point named `MakerWorldAnalytics-XXXX`. The display shows its randomly generated password and local address. Join that network, then open the shown address (normally `http://192.168.4.1`).

Enter the home Wi-Fi network, its password, a public MakerWorld username or profile URL, timezone, refresh interval, brightness, theme, clock format, update channel, and automatic update-check preference. The device saves the details locally, restarts, joins the selected Wi-Fi, and makes a direct TLS-validated request to the public profile page.

No supplied test profile is compiled into firmware. The portal never redisplays or serial-logs the submitted Wi-Fi password.
