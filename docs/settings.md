# Settings

The alpha portal persists the device name, public profile identifier, timezone, refresh interval, brightness, theme, clock format, OTA channel, and update-check preference in NVS. Wi-Fi credentials are stored separately in NVS and are never included in logs.

The on-device **SETUP** control opens the same password-protected local portal after first connection. Leave its Wi-Fi fields blank to retain the existing network. Touch calibration and local portal PIN management are tracked as follow-up work before a stable release.
