# Settings

The alpha portal persists the device name, public profile identifier, timezone, refresh interval, brightness, theme, clock format, OTA channel, and update-check preference in NVS. Wi-Fi credentials are stored separately in NVS and are never included in logs.

The current alpha enables the local first-connection portal. On-device settings, touch calibration, local portal PIN management, and destructive-action confirmations are tracked as follow-up work before a stable release.
