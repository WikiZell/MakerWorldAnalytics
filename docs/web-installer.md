# Web installer

The GitHub Pages installer targets only the standard single-USB ESP32-2432S028R. Use Chrome or Edge with a USB data cable. Release automation publishes a versioned ESP Web Tools manifest only after the bootloader, partition table, OTA metadata, and application binary are built and the application is hashed.

Do not use the installer for two-USB, ST7789, ILI9342, or other CYD variants until a dedicated verified build environment is released.
